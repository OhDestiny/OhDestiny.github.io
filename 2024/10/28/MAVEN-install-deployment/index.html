3. idea中配置

主要配置以下文件

为以后的每一个项目都配置：

setting –> new project setting –> 其他的同上就行

4. idea中使用maven创建普通javaSe项目

测试类名：XXXTest TestXXX
测试方法：xxxTest

出现问题： Test注解一直没有解析到，但是却可以使用mvn的Test运行Test的程序

解决：清除ide的缓存，就好了。

  • 创建一个空项目

  • 创建一个模块

  • 在java目录下边创建包，编写项目的源码

  • 在test目录下边创建包，编写项目的测试代码
  • pom.xml文件添加相关依赖，比如junit的依赖

5. 使用maven创建javaweb项目

  1. 创建一个新模块 new module
  2. Maven Archetype选项 —> maven-archetype-webapp

这个时候就会有一个javaweb的目录结构

然后只要添加相关依赖，然后配置tomcat就可以直接运行这个项目。

6. 导入Maven项目

  1. 直接打开项目的结构窗口，file上

  2. 点击moudle–> 新建模块 –>导入某块 Import module from external model –> create OK
