数据库概述1. 数据库（DB database） 数据库是“按照数据结构来组织，存储和管理数据的仓库”，是一个长期存储在计算机内的，有组织的，可共享的，统一管理的大量数据的集合。数据库并不是随意存放数据的，它具有一定的规则，负责查询的效率会低。 数据库中可以存文本，也可以存图像，音乐，声音。 其实我们熟悉的excel表 就是一种数据库，但是我们在excel表中操作数据的时候，比较麻烦，需要鼠标点击。而MYSQL这个管理系统则可以直接使用语言操作数据。 2. 数据库类型2.1 关系型数据库 关系型数据库是依据关系模型来创建的数据库，所谓的关系模型就是“一对一，一对多，多对多”等的关系模型，关系模型就是二维表格数据，因而一个关系型数据库就是二维表及其之间的联系组成的数据组织 关系型数据可以很好的存储一些关系模型的数据，比如一个老师对应多个学生，一本书对应多个作者，一本书对应一个出版日期。 关系模型包括，数据结构（数据存储的问题，二维表），操作指令集合（SQL语句），完整性约束（表内数据约束，表与表之间的约束） 2.2 非关系型数据库 noSQL not only sql ...
